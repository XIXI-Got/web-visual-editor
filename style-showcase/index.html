HOW IT SWITCHES

切换只发生在 token 层

01

选一种风格

页面根节点只挂一个 data-style，三套 token 各自成组，互不污染。

02

组件吃变量

面板、按钮、标签全部只读 var(--*)：换色、换圆角、换模糊都不用改选择器。

03

结构一动不动

同一份 DOM、同一套栅格与断点。风格是皮肤，不是另一张页面。

同一张页面，
下一套皮肤随时就位。

把风格做成 token 组，交付时换的是风格库里的记录，不是重做一遍页面。
