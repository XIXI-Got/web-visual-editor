# 网页修改器 · 功能概要（给豆包写文案用）

> 使用方式：把下面「产品资料」整段贴给豆包，再贴最后的「给豆包的指令」即可。

## 一、一句话定位

**AI 负责整体架构，网页修改器负责审美和细节打磨。**
一个能直接在网页上改的工具：框选就能改、拖拽就能动，AI 只改你圈定的范围，专门解决 AI 生成页面之后的「最后一公里」微调。

## 二、目标用户与场景

- 主要：**设计师**（AI 出稿后的风格、细节、统一性调整；不想为几像素反复找开发/反复跟 AI 描述）
- 也适合：**前端**（快速改文案/间距/位置，不用重开项目、重新构建）
- 也适合：内容运营、独立开发者、一人公司
- 典型场景：AI 一键生成落地页 / 官网 / 活动页之后，需要精细微调、多页风格统一、交付前打磨

## 三、核心痛点

1. 一键 AI 生成很快，但离「能交付」还差最后一公里：字距、留白、按钮质感、页面之间的统一。
2. 这最后一公里最花时间的是**沟通**：改个字号要一个字一个字跟 AI 说；挪个位置要描述「向上 20px、向右 20px」。
3. 多页面风格各改各的，审美不统一。
4. AI 改完不可控，不敢直接用；改完还要找开发落地。

## 四、功能清单（按使用流程）

### 1. 直接在网页上改（可视化、所见即所得）
- 鼠标框选/点选页面元素，选中即可编辑；支持多选、选父级
- 直接拖拽移动元素，**网格 + 相邻元素自动吸附**，拖到哪停在哪，不用报像素
- 拖动调整大小；对齐工具（左/中/右、上/中/下等）
- 改文字内容、字号、字重、颜色、行高、字距、圆角、阴影、宽高、位置
- **小键盘 `+` / `-` 直接调字号**（文字元素）/ 调宽高（其它元素）
- `Ctrl + ←/→` 调字距，`Ctrl + ↑/↓` 调行距
- 图片替换、隐藏/删除元素、复制粘贴样式
- **撤销/重做**（Ctrl+Z / Ctrl+Shift+Z），有历史记录，可回退多步
- 所有改动实时预览，改完看到的就是最终效果

### 2. 人机协作：AI 只改你圈定的范围
- 在页面上**拖一个框选中一块区域**，把这块交给 AI
- 「✦ AI 调整」对话框：输入需求（如「更克制，留白多一点」），自动带上**项目路径 / 当前页面 / 选中的元素**上下文发给对话里的 AI
- AI 只改选中的区域，不整页重写；改完不满意可以一步撤销
- 支持「重新框选元素」，随时换范围
- 支持在 DSH 里用，也支持独立窗口/工作台里用

### 3. 风格库：按你的设计规范改，不跑偏
- 从本地目录**提取现有设计规范**（支持 design-tokens.json / UI-SPEC.md / CSS tokens）
- 生成风格卡（含配色、字体、圆角等 token 摘要 + 自动封面）
- 一键把风格应用到项目：生成 `style-brief.md` 等 Agent 可读的规范说明
- 可保存/删除风格，多个项目复用；配合 AI，让 AI 按这套规范改，多页风格统一
- 解决「AI 味 / 模板感 / 审美不统一」

### 4. 网页工作台（独立前端界面）
- 项目列表：最近打开的项目 + 页面缩略图
- 打开项目 → 进入编辑视图（左侧/顶部工具栏：页面管理、保存、撤销重做、AI 调整、独立窗口、关闭）
- **独立窗口**：直接把当前项目开成独立窗口，布局与内嵌一致，不用中转
- 页面管理：列出页面、新建页面（空白/复制当前页）、重命名、删除、切换页面；页面间加导航条
- 风格优化页：风格库集中管理
- 编辑历史/版本：每次保存或关键操作有记录，可回看
- 主题切换（纸面/深色）、文件夹选择、**不改目标项目配置文件**

### 5. 交付：固化回源码
- 一键「固化」：把页面上的改动写回项目源码（生成/更新 CSS、把覆盖写进页面）
- 自动**备份**原文件，可恢复
- 固化后刷新/重新打开真实页面就是改完的样子，前端直接收结果
- 支持静态站和 Vite 项目；Vite 用临时插件启动，**不修改目标项目的 vite.config，不往项目里装东西**

### 6. 兼容与细节
- Windows + DSH（DeepSeek Harness）插件形态：右侧栏原生标签页，也可从工作台独立打开
- 支持静态站（HTML）与 Vite/React 项目
- 中文界面；快捷键与操作提示在 README 有完整说明
- 5 套自动化测试（单元 + 宿主 + 渲染端 + 撤销 + 工作台）共 122 项检查，全部通过

## 五、和其他方案的区别（可说，但别拉踩）

- 不是「又一个 AI 生成器」：生成之后的事才是它的主场
- 不是「让 AI 重做一版」：**只改你圈定的那一块**，改动可控、可撤销
- 不是「截图标注工具」：改的是真实页面，能固化回源码
- 不是「替代设计师/前端」：人定范围和审美，AI 做重复劳动

## 六、可用的事实/数字（避免夸大）

- 直接操作：框选即改、拖拽吸附、小键盘 +/- 调字号
- 撤销/重做、历史、备份
- 风格库：从 design-tokens / UI-SPEC 提取，应用到项目
- 页面管理：新建/复制/重命名/删除
- 固化：写回源码 + 备份
- 兼容静态站与 Vite，非侵入
- 122 项自动化检查通过

## 七、语气与禁忌

- 温柔、具体、少形容词；讲「过程」不讲「道理」
- 少用：替代前端 / 不用找开发 / 一键搞定 / 颠覆 / 神器
- 多用：最后一公里 / 人机协作 / 框一下、拖一下 / 只改这一块 / 审美留给人
