# DEMO 蓝白 · Demo Blue-White

> 自有示例页 `demo/muse.html` 初始版本的视觉系统。蓝白、轻玻璃、干净的产品演示气质；不是外部站点提取。

## 01 设计原则
- 白纸优先：页面以 `--paper #FFFFFF` 为主，浅灰蓝只做分区，不堆深色块。
- 一个强调色：`--blue #2563EB` 只用于按钮、关键图标、选中框和数据高亮，全页占比 < 8%。
- 轻层次：卡片靠 1px `--line` 与柔和蓝影分层，不用重玻璃、不用大面积渐变。
- 蓝白节奏：Hero 白、功能区 `#F5F8FD`、产品说明回到白，页脚浅灰蓝收尾。

## 02 色彩
| token | 值 | 用途 |
| --- | --- | --- |
| `--paper` | `#FFFFFF` | 页面底、卡片底 |
| `--soft` | `#F5F8FD` | 分区底、次级表面 |
| `--sky` | `#EAF1FF` | 浅蓝选中态、tag 底 |
| `--ink` | `#0B1220` | 标题与深色文字 |
| `--muted` | `#5B667A` | 正文 |
| `--dim` | `#8B95A8` | 元数据 |
| `--blue` | `#2563EB` | 唯一主强调 |
| `--blue2` | `#4D6BFE` | 蓝色亮部 / hover |
| `--line` | `#E6EBF4` | 1px 边线 |

## 03 字体
- `--font-sans`: Inter / Segoe UI / 微软雅黑 / 苹方，标题 800，正文 400–600。
- `--font-mono`: Consolas / SFMono，用于 eyebrow、代码感标签、数字。
- 中文标题保持 700–800，不落到 500。

## 04 版式
- 设计基准 1440，单一 `--u = clamp(.45px, 100vw/1440, 1px)`。
- 容器 `width:min(1200u, 100% - 2*gutter)`，`margin-inline:auto`。
- 分区纵向 `86u`，主栅格 1.02fr / .98fr，移动端单列。

## 05 组件
- 按钮：`pill`，主按钮蓝底白字；ghost 白底 1px `--line`。
- 卡片：`md/lg` 圆角、白底、1px `--line`、蓝调柔和阴影。
- 玻璃卡：仅 Hero 拼贴与浅色预览使用，白/浅蓝半透明，不做深色玻璃。
- 选中框：2px `--blue`，标签蓝底白字。

## 06 动效
- `--ease-out` 160–280ms，hover 只做颜色/阴影/位移 ≤ 2px。
- 页面加载可做轻上浮；`prefers-reduced-motion: reduce` 时全部关闭。

## 07 影像与文案
- 影像只做产品截图 / UI 拼贴，白底衬底，圆角与卡片一致。
- 文案短、动词开头；中文避免过度营销词。

## 08 响应式
- 结构断点：980px 导航收起、720px 单列、560px 页脚单列。
- 任何宽度 `scrollWidth <= innerWidth + 1`。

## 09 令牌与交互
- 颜色 / 字体 / 圆角 / 阴影 / 间距 / 动效均来自 `design-tokens.json`。
- 不新增主色；蓝色只作强调，不与第二强调色混用。
