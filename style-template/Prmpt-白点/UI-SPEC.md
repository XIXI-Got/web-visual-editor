# Prmpt 白点 — UI 规范

**Prmpt Portfolio / 白点作品集设计系统**
版本 1.0 · 2026.11 · 参考视口 1440 × 960 / 移动端 390 × 844

> 一张白纸、一片会呼吸的点阵、一枚 300px 的巨字标题。用整屏定格的滚动节奏，把作品排成一份安静的视觉档案。
>
> **本规范为纯文字 / 线框规范，不附任何照片、截图或预览图；影像只以比例、位置与裁切参数记录。**
>
> **硬约束速读：** 单色纸面（`--paper #FBFBFB` / `--ink #000`，无彩色）· 三套字体（Meutas / Inter Tight / JetBrains Mono）· 4px 间距阶 · 圆角只用 0 与 999px · `100vh` 定格面板 · 34px 点阵底层。详见 02 / 03 / 04 / 06 节。

**配套文件**

- CSS 令牌：`design-tokens.css`
- JSON 令牌：`design-tokens.json`
- 参考实现：Prmpt 作品集源码（React + Tailwind v4 + GSAP / Lenis）

## 01 · 设计原则

| 原则 | 说明 |
| --- | --- |
| **Paper first / 纸面优先** | 全站只有 `#FBFBFB` 与 `#FFF` 两种白。任何区块先留白再放内容，单屏黑块面积 < 5%；一旦开始堆卡片、加底色，版面立刻变成普通落地页。 |
| **Dots are paper / 点阵即纸** | 34px 点阵只作为全站底层画布与鼠标回应，不叠在图片、文字或按钮上；它不是装饰贴图，也不参与转场叙事。 |
| **Type as architecture / 大字即结构** | 章节标题 52–120px、Hero 300px，用字号本身划分章节；正文退回 14–18px。不要出现 28–44px 的"中间字号"大段文字。 |
| **One pose per screen / 一屏一姿态** | 每次滚动停在一屏一个构图上；章节之间是整屏推进 + 定格，不是连续下滑的长页面。 |
| **Quiet ink / 安静的墨** | 无彩色、无渐变、无发光；层次只靠字号、字重与留白建立，强调色就是黑本身。 |

一句房屋规则：**像一本装订好的作品档案，而不是一个会动的落地页。**

### 配比

UI 表面近似配比：**纸面 86% / 黑字与结构 10% / 点阵灰 3% / 描边 1%**。没有彩色强调色——强调靠满黑块（按钮、光标）与字号跳变实现，满黑面积单屏 < 5%。

### 对比度与使用约束

| 组合 | 对比度 | 结论 |
| --- | --- | --- |
| Ink / Paper | 20.29:1 | AAA，标题与结构 |
| Ink 80% / Paper | 12.35:1 | AAA，中文正文 |
| Ink 70% / Paper | 8.39:1 | AAA，次级文字 |
| Ink 55% / Paper | 4.72:1 | AA，正文与元数据下限 |
| Ink 45% / Paper | 3.33:1 | 仅 ≥24px 大字 |
| Ink 40% / Paper | 2.84:1 | 仅装饰；禁止承载信息 |
| Ink-strong / Paper | 17.80:1 | 点阵与图形 |

规则：

- 不使用彩色、渐变与发光；阴影只用纯黑半透明，且只在 hover 时出现。
- 纯白只作图片与卡片衬底，页面底色固定 `#FBFBFB`。
- 正文（≤18px）不得低于 `--ink-55`；`--ink-45` / `--ink-40` 只允许大字或装饰。源实现里 15px 分类说明用了 40%，落地时应提升到 55%。
- 边框只有两种：1px 半透明黑（`.5 / .7`）或 2px 纯黑角标；不加重、不加圆角描边。
- 禁止纯黑阴影以外的彩色阴影；禁止把阴影作为卡片常驻效果。

### 排版规则

- 拉丁展示只用于 Hero 标题与年份，全部 UPPERCASE；Meutas 在中文环境没有字形，中文标题必须替换为**思源黑体 / 苹方 700–800**，不得落回细体。
- 章节标题单行（nowrap），允许大幅出血与贴边，但正文必须保持 24 / 64px 边距。
- 中英混排：英文标签全大写、`.08–.30em` 字距；中文正文不加字距（0）。
- 正文行宽 36em（约 648px @18px），不超过 40em；不两端对齐、不用 hyphenation。
- 数字与年份统一 en dash：`2023–2026`；页码/百分比不补零。
- 中文正文行高 1.65，英文正文同样 1.65；标题行高一律收紧到 1 或以下，避免出现"行间空洞"。

## 04 · 版式与构图

### 页面节奏

全站是一块 `100vh` 的固定面板，由一条隐藏滚动条（初始 800vh、实测约 7.38 屏）驱动。每次滚动把整块面板推进一屏：

| 章节 | 滚动长度 | 停留 | 关键动作 |
| --- | --- | --- | --- |
| Hero | `0.50 × vh` | — | 点阵 scale `1 → 9`、白色 veil 覆盖、标题下移淡出 |
| Profile | `0.90 × vh` | hold `0.45` | 简介面板自下而上覆盖首屏 |
| Designs | `1.15 × vh` | hold `0.50` | 3D 封面环旋转 → 三栏分类 → 品牌卡落位 |
| Brand | `0.905 × vh` | — | 品牌卡展示（承接 Designs 尾部） |
| Poster | `1.678 × vh` | — | 标题 3 行拆分放大、三波海报替换 |
| Culture | `1.10 × vh` | — | 横向画廊拖动 + 结尾页在最后 `0.71` 段升起 |
| End | `1.15 × vh` | — | 谢谢 Thank you / 名字 / 回顶按钮 |
| 合计 | `≈ 7.38 × vh` | — | 7 个定格姿态 |

层叠关系：点阵画布 `z-0` → Hero 标题 `z-5` → 章节固定面板 `z-10` → 结尾页 `z-15` → 导航 `z-40` → 自定义光标 `z-50` → 作品灯箱 `z-80/90`。

### 页面栅格

| 项 | 值 |
| --- | --- |
| 内容最大宽 | `1400px`（封面环舞台）/ `960px`（分类行）/ `36em`（正文栏） |
| 列布局 | Profile 两列；Designs 分类三列；Poster 每波 5 张；Culture 横排 |
| 列间距 | 64 / 96px（Profile）；32px（卡片与画廊） |
| 页面左右边距 | 24px（phone）→ 64px（lg）；Poster 章节为视口宽 `8%` |
| 顶部安全区 | 导航高 58 / 76px；章节标题 top `11vh` |

### Hero 解剖

| 项 | 值 / 规则 |
| --- | --- |
| 舞台 | `100vh × 100vw`，fixed 层，`overflow: hidden` |
| 背景点网 | 以视口**右下角**为圆心，26 圈同心圆点阵向外扩散；点径从中心 `6px` 递减到外缘 `1px`，透明度 `.92 → .20`；只作 Hero/主页底层，不压字；点网不裁切、可溢出容器满屏铺开；滚动时随点阵 scale `1 → 9` |
| 标题中心 | 视口中心上移 `200px`，实体再下移 `20px` |
| 标题规格 | Meutas `300px` / 500 / 行高 1 / `.02em` / UPPERCASE |
| 轮廓回声 | 同一文案下移 `50px`，透明填充 + `3px #111` 描边 |
| 主视觉 | 底边 `-200px`，高 `92vh`，宽 `≤70vw`，`object-fit: contain` 贴底，水平居中（本版为空白占位） |
| 眉题 / aside | 顶部安全区 80 / 96 / 112px；mono 10–12px `.30em`，左右分置 |
| 主文 | 左下，`max-w 448px`，mono 12–14px，上移 50px |
| CTA | 左下：黑块按钮（四角角标）+ 40 / 44px 箭头方块 |
| 年份 | 右下，Meutas `36 → 110px` |
| 滚动 | 0 → 0.5vh：标题按 scrollY 线性淡出并下移；点阵 scale 1→9；veil opacity 0→1 |

### 章节解剖

**Designs（封面环）**

| 项 | 值 / 规则 |
| --- | --- |
| 标题 | top `11vh`，居中，双语并排，`52 → 88px` |
| 3D 环 | 5 张封面，跨度 `160°`，半径 `490px`，透视 `1600px`；卡片 `min(280px, 22vw) × calc(46vh - 200px)` |
| 视差 | 鼠标 ±22px / ±14px，深度缩放 `0.78 → 1.06` |
| 分类行 | 底部 `7vh`，`max-w 960px` 三列；中文 `26 → 34px`、英文 `22 → 30px` |
| 品牌卡 | `top 20% / left 36% / right 6%`，3 张 `3:4` 横排 |
| 离场 | 环旋转 +95°、卡片右移 110vw、白色遮罩收尾 |

**Poster（海报波）**

| 项 | 值 / 规则 |
| --- | --- |
| 中文标题 | `38 → 78px`，top `11vh → 14vh` 随拆分上移 |
| 英文标题 | 3 行叠印：`88px → 20vh`，字距 `.015 → .03em`，描边 `0 → 2px`，行偏移 `1.05em` |
| 卡片 | `2:3`，宽 `min(340px, 28vw)`，3 波 × 5 张 |
| hover | 自身 `-32px / 1.12`；邻居左右让开 `±42px`；阴影 `posterHover` |
| 灯箱 | 高 `82vh`、宽 `2/3 高`，`620ms` POP 缓动 |

**Culture + End（画廊与结尾页）**

| 项 | 值 / 规则 |
| --- | --- |
| 标题 | 左对齐，边距 24 / 40px；中文 `32 → 54px`、英文 `36 → 64px` |
| 画廊 | 条幅 `16:9`，高 `≤56vh`，宽 `≥min(78vw, 1200px)`，间距 32px，可拖拽 + 惯性 |
| 结尾页 | 覆盖在画廊之上，在 Culture 最后 `0.71 / 1.10` 段升起 |
| 结尾版式 | 居中：眉题 `16 → 18px / .22em`；标题 `64 → 120px / 90%`；名字 `22 → 28px`；回顶按钮 1px 描边 |

### 间距

- 基础单位：`4px`（半阶 `2px` 只用于描边偏移与图标对齐）。
- 间距阶：`2, 4, 8, 12, 16, 20, 24, 28, 32, 40, 48, 56, 64, 96`。
- 规则：区块之间固定 48 / 64 / 96；组件内部 8 / 12 / 16；文字之间靠行高，不叠加超过 24px 的 margin；页面左右边距必须对称（24 或 64）。

## 05 · 组件

> 每个组件只写这套风格特有的部分；通用按钮/表单不在此列。

### 导航 Navigation

- fixed 顶部，底色 `--paper`，高 58 / 76px（padding 16/24 + 26px 字）。
- 左：`PORTFOLIO` 18 → 26px / 500 / UPPERCASE / `-.04em`。
- 右：`PROFILE / 简介`、`DESIGN / 设计`，13 → 15px、`.08em`，间距 20 / 32px；末尾 20 / 28px 双横线菜单图标（描边 2.5）。
- 无下划线、无悬浮底色；hover 仅降到 60% 黑。滚动时不隐藏、不缩高。

### 角标按钮 CornerButton

| 状态 | 底色 | 文字 | 边框 | 圆角 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 默认 | `--ink` | `#FFF` mono 12px `.20em` | 无 | 0 | padding `40px / 14px`；四角 2px 黑线 16×16，外移 8px |
| hover | `rgba(0,0,0,.90)` | `#FFF` | 无 | 0 | 300ms 过渡，不加位移 |
| active | `--ink` | `#FFF` | 无 | 0 | 下沉 1px |
| 禁用 | `rgba(0,0,0,.35)` | `rgba(255,255,255,.7)` | 无 | 0 | 不显示角标 |

### 图标按钮 IconButton

- 40 / 44px 纯黑方块，白色箭头 18px；同款四角角标（12×12，外移 8px）。
- hover 背景 90% 黑；触控时最小热区补到 44×44。

### 描边按钮 OutlineButton（回到顶部）

- 1px `--line` 边框、无圆角、padding `24px / 12px`；12px / `.12em` / UPPERCASE。
- hover 反白：底色 `--ink`、文字白，300ms。

### 技能格 SkillChip

- 58 / 64px 正方形，1px 纯黑边框，居中 18 / 20px 代号（`-.04em`）。
- hover：上移 4px、放大 1.10、层级提到最上。

### 技能条 SkillBar

- 轨道高 7px，1px `--line-soft` 边框，内部纯黑填充（宽度 = 百分比）。
- 行 hover：整行上移 4px、放大 1.03；百分比 12px；文字 hover 时字距从 `-.02em` 过渡到 `.06em`。

### 分类标签 CategoryLabel

- 中文 26 → 34px / 700、英文 22 → 30px / 700，同基线并排，字距 `-.03em`。
- 说明 15 → 16px / 300，行高 1.5，颜色 `--ink-55`（源实现为 40%，按第 02 节提升）。
- 多语言标签居中排列；品牌分类在转场时会放大到 84px 并左对齐。

### 封面环卡 RingCard

- 无圆角、纯白衬底，尺寸 `min(280px, 22vw) × calc(46vh - 200px)`，图片 `cover` 满铺。
- 3D 变换：`rotateY + translateZ(490px)`，按深度设 z-index，背面隐藏。
- hover：上移 16px、放大 1.07，阴影 `cardHover`（`0 28px 44px rgba(0,0,0,.18)`）。

### 海报卡 PosterCard

- `2:3`，宽 `min(340px, 28vw, 可用宽 / n)`；白底、无圆角。
- hover：上移 32px、放大 1.12，阴影 `posterHover`（`0 28px 50px rgba(0,0,0,.45)`），邻居左右让开 42px；过渡 550ms `--ease-out`。

### 画廊条 CultureTile

- 条幅 `16:9`，高 `≤56vh`，宽 `≥min(78vw, 1200px)`；间距 32px，首件左侧 32px。
- 拖拽：指针 1:1 跟手，松手后惯性衰减（摩擦 .935，速度 < .18 停止）；滚动接近时按进度自动横移。

### 灯箱 Lightbox

- fixed 全屏，底 `rgba(255,255,255,.78)` + `backdrop-filter: blur(24px)`，无圆角。
- 品牌灯箱：水平序列高 `50vh`，图片 `max-w 70vw`，可拖拽 + 惯性；关闭圆钮 48px、1px 黑边、箭头 ↓。
- 入场：透明度 0→1（380ms `--ease-view`）；内容 `scale .86 → 1 / y 36 → 0`（420ms）。
- 海报灯箱：点击卡片后从原位置放大到目标框（`620ms`，`cubic-bezier(.22,1,.36,1)`）。

### 点阵光标 DotCursor

- 48px 圆环（2.5px 白描边）+ 居中 16px `P`（Inter Tight 500）；`mix-blend-mode: exclusion`。
- 仅 `≥1024px` 启用并隐藏原生光标；触屏与编辑器打开时隐藏，不承载任何功能。

## 06 · 动效

### 缓动

| 名称 | 值 | 用途 |
| --- | --- | --- |
| `--ease-out` | `cubic-bezier(.22, 1, .36, 1)` | 海报卡 hover、灯箱放大（550–620ms） |
| `--ease-view` | `cubic-bezier(.4, 0, .2, 1)` | 遮罩/灯箱淡入（350–420ms） |
| `--ease-slide` | `cubic-bezier(.4, .02, .12, 1)` | 画廊入场 `translateX(100vw → 0)`（1.42s） |
| `--ease-snap` | `1 − (1 − t)^1.23`（JS） | 整屏跳转：1.2s 走完 89%，末段收尾 |
| `--ease-hero` | `easeInOutCubic`（JS） | 首屏点阵缩放、面板推进 |

### 关键动效时序

| 动效 | 时长 | 延迟 / 错峰 | 说明 |
| --- | --- | --- | --- |
| 首屏推进 | `2400ms` | 滚动触发 | 点阵 scale 1→9、veil 0→1、标题淡出 |
| 整屏跳转 | `1500ms`（章节间 1700 / 2200 / 2400） | 停 240ms 冷却 | 9 个停靠点，可反向打断 |
| 海报换波 | `780–860ms` | 三波顺序 | 每波 5 张，旧波上移 80px 退出 |
| 画廊入场 | `1420ms` | 进入时一次 | 1.42s slide，之后交给拖拽与滚动 |
| 结尾页升起 | 滚动 1:1 | 最后 0.71/1.10 段 | 覆盖画廊，透明度到 1 后才可点击 |
| 悬停反馈 | `300ms` | — | 位移/透明；卡片 500–550ms |
| 封面环入场 | 随滚动进度 `0.04–0.44` | 每张错峰 32ms（进度 `.032`） | `x −42 → 0`、`y +22 → 0`、`scale .92 → 1` |
| 品牌卡落位 | 随滚动进度 `0.34–0.72` | 每张错峰 100ms（进度 `.1`） | `y 40 → 0`、`scale .94 → 1` |

### 交互细节

- 滚动：Lenis `lerp .1`、`smoothWheel`，由 GSAP ticker 驱动；关闭 `overscroll`。滚轮、↑↓ / PgUp·PgDn / Space、触摸滑动都触发整屏跳转。
- 点阵：34px 网格、点径约 6.4px、基准透明度 `.20`；鼠标 340px 范围内推开（最大 ±96px），速度衰减 `.92`、回位 `.012`，能量归零后停止 rAF；离屏暂停。
- 光标：跟随 `pointermove` 实时定位，`translate(-50%,-50%)`；滚动时不缩放。
- 首屏可交互元素（标题、主视觉、简介）支持拖拽微调位置，偏移量写入 localStorage；编辑器打开时禁用拖拽。

### 无障碍

- 必须支持 `prefers-reduced-motion: reduce`：整屏跳转、首屏推进、画廊滑行全部改为即时定位；点阵保持静态；只保留 ≤150ms 的透明度变化。
- 主动效数量：每个视口最多 1 个主动效（首屏缩放 / 封面环旋转 / 海报波替换不同时出现）。
- 动效不得承载唯一信息：所有内容在动画结束或关闭动效后都可读。

## 07 · 影像与文案

### 图像

| 类型 | 规则 |
| --- | --- |
| Hero 主视觉 | 透明 PNG/WebP，高 `92vh`、宽 `≤70vw`，`object-fit: contain` 贴底，底边外露 200px；本版为空白占位 |
| 品牌作品 | `3:4`，`object-fit: cover`，满铺、无边框 |
| 海报作品 | `2:3`，`object-fit: cover` |
| 文化墙 | `16:9` 条幅，高 `≤56vh` |
| 头像 | `1:1` 圆形，72 / 96px，1px 黑边，`object-position: center 18%` |
| 点阵纹理 | 34px 网格、点径 6.4px、`#141414`、透明度 `.20–.65`，全站固定底层 |
| Hero / 主页背景点网 | 圆形扩散点网：同心圆点阵 + 径向 mask，中心密、外缘淡；只出现在 Hero/主页首屏背景，不叠在图片、文字或按钮上 |
| 灯箱 | 品牌图最大 `70vw × 50vh`；海报图高 `82vh`、按 2:3 定宽 |
| 禁用 | 圆角、滤镜、彩色渐变、投影常驻、装饰贴纸、图片边框 |

- 作品图一律矩形满铺，靠裁切与留白建立秩序；悬停才允许出现阴影。

### Hero / 主页背景点网

```css
.hero-dot-net{
  position:absolute; inset:0; pointer-events:none; z-index:0;
  background-image:radial-gradient(circle,#141414 6px,transparent 6.5px);
  background-size:34px 34px; background-position:center;
  -webkit-mask-image:radial-gradient(circle at 50% 50%,#000 0 24%,rgba(0,0,0,.9) 38%,transparent 70%);
  mask-image:radial-gradient(circle at 50% 50%,#000 0 24%,rgba(0,0,0,.9) 38%,transparent 70%);
  opacity:.72;
}
```

- 点网只做 **Hero / 主页首屏背景**，位于 `z-0`，文字与 CTA 在其上。
- 点阵中心放在 **右下角**，中心密、外缘淡；点径从 6px 递减到 1px，形成向外扩散的圆，不要做成铺满全屏的均匀方格。
- 直接实现用 SVG 同心圆点阵（26 圈）；下面的 CSS 只作为快速兜底。
- 滚动推进时点网可随 Hero 点阵一起 `scale 1 → 9`，并保持 `prefers-reduced-motion` 下静态。
- 不在点网上叠加噪点、彩色渐变或投影。
- 内容图必须有描述性 alt；纯装饰点阵 `alt=""`。
- 不叠加噪点/纹理图层——点阵本身就是纹理。

### 文案

- 语气：档案式、克制、第一人称；像作品说明与观测记录，不像广告。
- 双语并置：中文 + English 同行或相邻；英文标签全大写或 Title Case，中文用短句。
- 年份统一 en dash（`2023–2026`）；范围写全，不省略。
- 标题长度：Hero ≤ 1 个单词；章节中文 2–4 字 / 英文 1–2 词；说明 ≤ 60 字。
- 禁用词：赋能、打造、极致、震撼、爆款、沉浸式、一站式、遥遥领先。
- 示例：

| Do | Don't |
| --- | --- |
| “品牌、海报与文化墙的作品档案。” | “极致视觉盛宴，燃爆全场！” |
| “Selected work 2023–2026. Brand identity, poster, and culture wall.” | “Welcome to my amazing world of design!!!” |

## 08 · 响应式与无障碍

### 断点

| 名称 | 值 | 主要变化 |
| --- | --- | --- |
| phone | `< 640px` | 单列；边距 24px（Hero 20px）；标题降一档；禁用 hover 位移 |
| tablet | `640 – 1023px` | Profile 仍单列；分类三列可压缩；导航间距 20px |
| desktop | `≥ 1024px` | Profile 两列 + 水平偏移；启用自定义光标与 hover 动效；边距 64px |
| wide | `≥ 1280px` | Hero 年份 110px；封面环与画廊按最大宽铺开 |

- 390 × 844 下不得出现横向滚动；Hero 巨字允许左右裁切（这是设计选择），但正文与按钮必须完整可见。
- 移动端关闭自定义光标、拖拽微调与惯性画廊；整屏跳转保留但时长缩短到 1.2s 内。

### 无障碍清单

- [ ] 正文对比度 ≥ 4.5:1（`--ink-55` 4.72:1 为下限）；大字 ≥ 3:1。
- [ ] `--ink-40` / `--ink-45` 只用于装饰或 ≥24px 大字。
- [ ] 焦点可见：2px 纯黑 outline + 2px offset；黑底按钮用白描边；不得移除 outline。
- [ ] 触控目标 ≥ 44 × 44px（箭头方块与导航小字需补热区）。
- [ ] 键盘可用：↑↓ / PgUp·PgDn / Space 整屏跳转并可反向；灯箱 Esc 关闭并锁定焦点。
- [ ] 动效可关闭（`prefers-reduced-motion`），关闭后内容顺序与可读性不变。
- [ ] 滚动劫持提供替代路径：导航可直接跳到 Profile / Designs，结尾页提供"回到顶部"。
- [ ] 图片 alt 语义正确；标题层级 h1 → h2 不跳级。
