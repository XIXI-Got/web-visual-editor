# PixelOS 95 像素桌面

Win95 经典灰的像素桌面：青绿桌面 + 2px 立体边框 + 像素字体 + CRT 扫描线，另有 GameBoy 绿豆沙与 8-Bit 霓虹两套皮肤。

> 提取来源：`pixelos_95.html`（单页模拟桌面）。主皮肤 `data-theme="win95"`，本文档以它为准，另两套皮肤见第 10 节。

## 01 设计原则
- **版面即桌面**：整个页面是一台 90 年代电脑——桌面底、窗口、40px 任务栏三层，不做现代网页的卡片流与居中大标题排版。
- **立体靠边框，不靠阴影**：浮雕一律用「2px 亮/暗边框 + 1px inset 内衬」画；禁用 blur 阴影、毛玻璃、大面积渐变、圆角。
- **0 圆角**：`border-radius` 全站为 0，出现任何圆角即判定走样。
- **像素字体只做标签**：`Press Start 2P` 只用于英文标签、数字、HUD；中文正文必须回落 `Courier New / SimSun`，否则不可读。
- **CRT 是氛围层**：扫描线是全屏 `pointer-events:none` 覆盖层，不占布局、可开关；关掉后页面依然完整。

## 02 色彩（经典灰 · Win95）
| token | 值 | 用途 |
| --- | --- | --- |
| `canvas` | `#008080` | 桌面底，全页唯一背景 |
| `surface` | `#C0C0C0` | 窗口 / 任务栏 / 按钮面 |
| `surfaceAlt` | `#DFDFDF` | 凹陷面板、菜单底 |
| `inset` | `#FFFFFF` | 输入框、画布、进度槽底 |
| `ink` | `#000000` | 文字与最暗边框层 |
| `accent` | `#000080` | 标题栏渐变起点、选中、反白 |
| `accentBright` | `#1084D0` | 活动标题栏渐变终点 |
| `muted` | `#4A4A4A` | 次级说明 |
| `accent2` | `#D12C2C` | 警示 / 关闭 |

- 桌面纹理只有一种：16px 网格上 `rgba(255,255,255,.14)` 的 1.5px 点阵。
- 直接压在青绿桌面上的文字必须用白色 + `1px 1px 0 #000` 硬阴影（Win95 图标标签法）：黑字压青绿只有 4.4:1，达不到 AA。
- 配色占比：青绿与灰面 ≥ 85%，海军蓝 accent ≤ 10%，红/绿/黄仅出现在图标与状态条（≤ 5%）。
- 三段进度条 `hp #D9383A` / `mp #2864D8` / `exp #2E9E44` 是唯一允许的饱和色。

## 03 字体
- `--font-pixel`：`'Press Start 2P', 'Courier New', monospace`，用于 8–10px 英文标签、时钟、得分（字距 .08em、全大写）。
- `--font-sans`：`'Courier New', SimSun, 'Microsoft YaHei', monospace`，正文与窗口文字主力，必须等宽。
- `--font-vt`：`'VT323', SimSun, monospace`，可选的大号数字/副标题。
- 中文替代：宋体优先（系统缺字时落微软雅黑），标题字重 ≥ 700；像素字体不用于中文长句。
- 字阶：窗口标题 12px/700、正文 12px/1.6、说明 11px、像素标签 9px、HUD 数字 10px；移动端正文字号不得小于 12px。

## 04 版式与自适应
- 设计基准 1440×900；布局单位 `--u: clamp(0.8px, 100vw / 1440, 1.15px)`，只用于间距与控件尺寸，字号用 `clamp()` 单独控制。
- 容器一律 `width:min(1120px, 100% - clamp(16px, 4vw, 48px)); margin-inline:auto`，禁止写死 px 宽度。
- 桌面隐喻允许绝对定位的“窗口”，但必须可降级：窄屏下窗口改为流式堆叠，`left/top` 像素定位不得用于常规内容布局。
- 360 / 480 / 768 / 1024 / 1280 / 1440 / 1920 七档下 `scrollWidth <= innerWidth + 1`，`body` 加 `overflow-x:clip`。

## 05 组件
- **窗口**：`2px` 亮边（上左）+ `2px` 黑边（下右）+ `inset 1px 1px 0 #DFDFDF` 内衬；标题栏 24px，`linear-gradient(90deg,#000080,#1084D0)`，白字 12px/700，左侧 10px 彩色方块标识；最小化/关闭是 20×20 凸起按钮。
- **按钮**：高 24px、`0 12px` 内边距、0 圆角；默认凸起（上左白、下右黑 + 右下 `inset #808080`），hover 仅 `filter:brightness(1.03)`，按下时边框反相并整体右移下移 1px；移动端高度提到 36px。
- **凹陷框**：上左 `#808080`、下右 `#FFFFFF`，外加 `inset 1px 1px 0 #000`，用于输入框、选择器、画布、进度槽。
- **状态条**：14px 凹陷槽 + 2px 内边距 + 纯色填充，条上不放文字，数值放槽外左侧标签。
- **任务栏**：底部固定 40px，左侧开始按钮 + 窗口标签，右侧凹陷托盘（📺 / 🔊 / 像素时钟）；开始菜单左边 28px 海军蓝竖条 + 反白 hover。
- **CRT 遮罩**：3px 扫描线（`rgba(0,0,0,.22)` 半幅）+ 6px RGB 竖条（红/绿/蓝 4%/2%/4%），`fixed inset:0; z-index:9999`。

## 06 动效
- 按钮、窗口开合 `transition:none`——90 年代没有缓动动画，只做瞬时位移。
- 皮肤切换：`background-color 250ms ease`、边框色 `100ms`，只过渡颜色不位移。
- 唯一的“大动画”是 8-Bit 旋转：`1.4s steps(4,end) infinite`，用于磁带/加载图标；图标 hover 仅 `scale(1.05)`。
- 音效为可选：方波 `square`、频率 580–880Hz、时长 40–60ms；默认可关。
- 必须支持 `prefers-reduced-motion: reduce`：关闭旋转、缩放与过渡，扫描线保留但可手动关闭。

## 07 图标与影像
- 图标按 16×16 网格手绘纯色矩形 SVG，`image-rendering:pixelated`，只允许纯色块，禁止渐变、发光、描边、圆角。
- 大图用“放大 16×16 像素画”的方式呈现，不加滤镜；emoji 只做 11–12px 小标签，不做主图标。
- 不使用照片；需要画面时用像素画/线框/纯色块代替。

## 08 响应式与无障碍
- 断点：600px 以下窗口单列、任务栏标签横向滚动；400px 以下标题栏只留图标与关闭。
- 对比度：`#000` on `#C0C0C0` ≈ 11.5:1、白字 on `#000080` ≈ 16:1、`#4A4A4A` on `#C0C0C0` ≈ 4.9:1，均达 AA；标题栏渐变终点 `#1084D0` 上白字约 4.0:1，属下限，文字必须 700 字重，必要时加深终点。
- 焦点可见：1px 点状 `#000` 轮廓 + `outline-offset:-4px`（Win95 原生方式），禁止 `outline:none`。
- 触摸目标 ≥ 36×36px；纯装饰层（CRT）必须 `pointer-events:none` 且对读屏隐藏。

## 09 令牌与交付
- 全部数值以 `design-tokens.json` 为准，CSS 变量前缀 `--`；皮肤切换用 `data-theme="win95|gameboy|neon"` 覆盖同名变量。
- 禁止新增：圆角、模糊阴影、第三种强调色、现代无衬线正文、渐变按钮。
- 交付前自检：0 圆角、边框亮上左下右黑、字体等宽、七档宽度无横向滚动。

## 11 禁止项清单
1. 任何 `border-radius`（含 1px 微圆角）。
2. `box-shadow` 模糊阴影 / `backdrop-filter` / 半透明卡片。
3. 用 1px 细边框代替 2px 立体边框的“现代扁平化”改法。
4. 正文换成 Inter / 思源黑体等现代无衬线（可读性会破坏时代感，必须等宽）。
5. 把像素图标改成线性图标、把纯色块换成渐变。
6. 用 `left/top` 像素位移做常规内容布局。
7. 大面积使用 accent 海军蓝（>10% 面积会失去 90 年代克制感）。
